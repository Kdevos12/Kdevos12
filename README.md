I make software and personal experiments driven by curiosity, especially where computation meets difficult ideas. I’m interested in **mathematics, biology, neuroscience, cognitive science, and artificial intelligence**.

I’m drawn to cognitive difficulty: building tasks that test different kinds of thinking, not only memory. I try to take neuropsychological principles seriously without presenting personal projects as clinical tools or validated interventions.

### Things I build

- **Cognitive experiments** — browser-based tasks involving attention, memory, reasoning, and learning.
- **Small software and prototypes** — explorations across computation, scientific ideas, and the web.
- **KDEVOS** — my personal site and a changing archive of projects, writing, and experiments.
